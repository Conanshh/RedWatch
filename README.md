# 🚌 RedHuawei Monitor PWA
Monitor de tiempos de llegada para buses Red (ex-Transantiago), optimizado para dispositivos móviles y notificaciones inteligentes.

## ✨ Características
- **Notificaciones Inteligentes:** Modo "Fijo" para actualizar una sola tarjeta o modo "Múltiple" para vibrar en cada aviso.
- **Modo PWA:** Instalable en Android/iOS.
- **Auto-Refresh:** Actualización cada 30 segundos con sincronización silenciosa.
- **Historial y Favoritos:** Almacenamiento local para acceso rápido.

## 🛠️ Tech Stack
- **Frontend:** Astro, React.js, Service Workers API.
- **Backend:** FastAPI (Python).
- **Despliegue:** Vercel (Frontend) & Render (Backend).
